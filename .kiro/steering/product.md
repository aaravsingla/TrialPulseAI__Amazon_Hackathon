# Product Overview

TrialPulse AI is a clinical trial monitoring platform that provides real-time oversight of multi-site clinical studies. The system combines data quality monitoring, risk detection, and AI-powered analysis to help trial managers identify and respond to operational issues.

## Core Features

- **Command Center Dashboard**: Real-time visualization of site performance metrics, DQI scores, and critical alerts across all trial sites
- **Digital Twin**: Interactive site monitoring with geographic visualization and performance tracking
- **AI Chat Interface**: Natural language query system for analyzing trial data and identifying risks
- **Multi-Agent Workspace**: Automated analysis system that simulates coordinated agents (DataQuality, SitePerformance, Orchestrator) to diagnose issues and propose action plans

## Key Metrics

- Data Quality Index (DQI): Composite score tracking visit completion, query resolution, and safety reporting
- Site Status: Real-time monitoring of patient enrollment, overdue items, and operational health
- Risk Detection: Automated flagging of sites with >10 overdue items or DQI <60

## Data Source

The system processes clinical trial data from EDRR (Electronic Data Review Report) Excel files, aggregating subject-level data to site-level insights.
